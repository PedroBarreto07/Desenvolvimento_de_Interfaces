## Objetivo

Repositório criado para armazenar os projetos, exercícios e atividades desenvolvidos durante a disciplina de **Desenvolvimento de Interfaces**.

---

## Sobre a matéria

A disciplina de Desenvolvimento de Interfaces tem como objetivo capacitar o aluno a criar interfaces digitais funcionais, acessíveis e visualmente agradáveis, utilizando as principais tecnologias do desenvolvimento web.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
